This web map was built with climbers in mind. California is probably the greatest area on the planet for the sport: From the granite of Yosemite to the High Alpine climbing in the Sierras, all the way to the mazes of boulder in Joshua Tree, there is both volume and variety. Climbers planning a trip to California may want a quick refernece to learn about the rock *and* climate conditions (hence the ecoregions and not climate regions). The map displays the Level 3 ecoregions of California as defined by the EPA (https://dmap-prod-oms-edc.s3.us-east-1.amazonaws.com/ORD/Ecoregions/reg9/SW_reg9_eco.pdf) using a unique color classification scheme. It also uses Font Awesome Icons to display the Latitude and Longitude coordinates for Climbing Areas in California (sourced from Mountain Project). The map tiling is provided by Leaflet. Jquery is used to simplify the JS syntax. Font Awesome provides the icons used in the web map. The color scale comes from Chroma. I use ESRI's world imagery basemap for the basemap.
